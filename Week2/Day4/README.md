## Controllers vs Minimal APIs Comparison

 Controllers :
  Organized inside controller classes using attributes.
  Better for large and complex applications.
  Easier to maintain and organize.
Minimal APIs :
 Defined directly in Program.cs using MapGet, MapPost, etc.
 Suitable for small and simple APIs.
 Requires less code and setup.


In this project, Controllers were used for structured endpoints, while Minimal APIs were implemented for comparison.
