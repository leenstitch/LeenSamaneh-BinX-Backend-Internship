Week 4 — Day 5: API Security & Hardening

Today I focused on improving the API security by implementing Rate Limiting, CORS, HTTPS, HSTS, and security headers. I also reviewed SQL Injection prevention with Entity Framework Core and completed the Week 4 security hardening tasks.

Topics Covered

CORS: Configured a named CORS policy to allow requests only from the intended frontend origin.
HTTPS & HSTS: Enabled HTTPS redirection and HSTS to enforce secure communication.
SQL Injection Prevention: Reviewed how EF Core parameterizes LINQ queries and protects against SQL injection by default.
